# A folder shows its own Works; every card in a view shares one box shape

Picking a Hub folder that has subfolders shows only the Works kept directly in it, not every Work
below it. A large Books Section holds thousands of Works, and a flat wall of them answers no question; the
folder columns already reach everything else. A folder that keeps nothing itself shows its
subfolders as tiles (a mosaic of up to four covers or frames, with a Work count) so the pane is
never empty. Search, a Medium or Mark filter, or the Show all button still list every Work below,
because then a question has been asked.

This is a Settings choice (`hub-folders`), since people browse differently: only own Works (the
default), subfolder tiles above own Works, or every Work below. The setting is kept so the future
app can offer the same choice.

Every card in a view uses one thumbnail box: portrait when most Works shown are covers, landscape
when most are videos. The minority fits inside with a plain margin. Mixed portrait and landscape
boxes made rows ragged.

## Considered Options

- Show nothing until a leaf folder is picked: the pane is empty at every level above the leaves.
- A recently-added strip above the tiles: one more row to scroll past on every folder.
- One fixed box shape everywhere (4:3 or 3:4): shrinks covers in Books or video frames in
  Learning, where each is the main thing.
