# A Section's kind decides its Works, guessed from its contents and changeable

The Hub page hard-coded how each Section makes Works. FilesViewHub gives every Section one of four
kinds, guesses it from the folder's contents, and lets the person change it, each shown with a
picture of a sample folder and the cards it makes:

- Courses: a folder per course, lessons inside.
- Books and documents: files with the same name in different formats are one card.
- Collections: a folder full of files is one card, like an album or an activity pack.
- Videos and files: every file is its own card.

These are the Hub's existing rules (Learning, Books, Kids, Cooking) given names.

## Considered Options

- The person always picks: one more step on first run for a choice the contents usually show.
- One generic rule: a course with 80 lessons would become 80 cards.
