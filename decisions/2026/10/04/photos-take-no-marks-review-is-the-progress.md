# Photos take no Marks; the count of Photos to review is the progress

This reverses the Mark part of `decisions/2026/10/04/an-event-is-the-work-in-photos.md`. Done on an Event, shown as "Sorted", meant "I have gone
through this event", but the person using the Hub could not tell what was sorted, or into what. It was
also a second button beside Sort, and Sort set it automatically, against the rule that a Mark is only
set by hand. Photos now take no Mark and no Tick. The one action is Review: for each Photo the Hub
suggests may not be needed (an extra Similar shot, a Copy, Junk), the person keeps it or sets it aside.
Months, years, events and days show how many Photos are left to review, and "reviewed" when none are.
An event with nothing to review needs nothing. The choices are kept in the browser apart from the Marks
and go into the same export.

## Considered Options

- Keep Done on Events with a clearer name: still a second button for the same idea, and still set
  automatically by Review.
- Progress as the share of events done: events with nothing to review would count as work left.

## Consequences

- Retuning the Event gap no longer orphans anything in Photos: Review choices are kept per Photo, not
  per Event id.
