# Security

## Reporting a problem

Please report a security problem privately, not in a public issue: on GitHub, open the
**Security** tab of this repository and choose **Report a vulnerability**. Say what you found, how
to see it happen, and which version and system you used (Settings shows the version and build).

You get an answer within a week. Once a fix ships, the report is made public with credit to you,
unless you ask otherwise.

## Supported versions

Only the newest release gets fixes.

## What the app may do

FilesViewHub reads the folders a person ticks and never writes into them, except to move photos
the person marked Not needed in Review, when they press Move. It goes online only when the person
presses Search in Choose a cover…. **Settings, What this app does** lists everything it stores,
reads, runs and sends; anything it does beyond that list is a security problem worth reporting.
